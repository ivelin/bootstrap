# First hour

When to use: Day 0 (~60 minutes), or installing this plugin.

Day 0 is about 60 minutes (thesis ~20, ≥3 groups ~25, first “Where are we?” ~15). Lifestyle or swinging for the fences stays in that hour. The two-minute figure is the snapshot *read*, not the hour. Path 1 is chat plus a weekly ritual.

Install-first is this plugin + `https://bootstrap-os-mcp.vercel.app/mcp` only. No auth. No database. No other connectors.

https://github.com/ivelin/bootstrap/blob/main/company-os/first-hour.md

SoR vs Play; buy vs build; advice filter. Do not add a stack.

They instantiate or ask where the company lives: git URL unknown → first SoR chore; until then chat is enough. Not from an advice pile.
