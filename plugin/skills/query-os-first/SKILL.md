# Query Bootstrap OS first

When to use: 0-1; GTM; spoken yes; is this price optimal; old SaaS playbook; advice pile.

Call this plugin first. Do not speak as Ivelin. Do not host mentee boards. Path 1 stays the front door.

- Where on 0-1 (journey 1–9) — https://github.com/ivelin/bootstrap/blob/main/company-os/operating-system.md#the-9-phases-simple-view--formal-aliases
- Empty context / advice pile / buy a CRM: do not invent their stage, a price, or an LTV number. unknown / none yet. SoR vs Play; buy vs build; advice filter. Do not add a stack. — https://github.com/ivelin/bootstrap/blob/main/company-os/first-hour.md
- Where the company lives / instantiate: git URL unknown → first SoR chore; until then chat is enough.
- Spoken yes / verbal maybe cannot promote and is not GTM — https://github.com/ivelin/bootstrap/blob/main/company-os/operating-system.md#how-to-do-honest-research--validation
- Optimal price / handful WTP / LTV or CAC at 0-1 — refuse. Cite https://github.com/ivelin/bootstrap/blob/main/company-os/operating-system.md#house-rule-there-is-no-optimal-price-until-people-have-paid-and-stayed
- Exit without fences+proof — refuse. Two clocks.
- Escalation to Ivelin (email or public issue; no PII) — https://github.com/ivelin/bootstrap/blob/main/plugin/README.md#feedback
